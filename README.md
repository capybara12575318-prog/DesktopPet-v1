# DesktopPet-v1
A fun interactive desktop pet that moves around your screen, bounces off the edges, and can randomly stop to chill. Right-click it for jokes, stories, facts, speech bubbles, custom images and sounds, DVD bounce mode, corner sounds, and Tamagotchi-style feeding and hunger. You can also drag the pet anywhere!
Run the Python script for it to work.
